### Please follow these rules when submitting pull requests:

1. Do not copy and paste code from projects that are not compatible with GPLv3. When copying license compatible code, you must declare where the code is from and respect the original licensing.
2. Do not submit commits co-authored with LLM services. LLM services cannot own / co-own code with you. If YOU give the intend to a LLM service to produce code, YOU are the one responsible for your code. ie. Do not send in commits with co-author declaration like `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`, own up to YOUR own code that YOU generated.
3. LLM usage declaration is up to you.
4. When creating pull requests made with LLMs, YOU have to fully understand the changes you have made, and do not rely on the LLM to fully handle the review process. Consulting the LLM is okay, but do not degrade it to you just being the messenger between the reviewer and the LLM.
5. When generating changes with LLM, keep the changes concise, and do not incur unrelated code and code formatting changes.

If these rules are ignored, your pull request might be closed without further explanation.
